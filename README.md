this is a college project i made.
it uses an esp eye to constantly stream data over the serial port and local server/wifi.
it has detailed code on using the esp eye for this function.
it uses the facial recognition library and a python script to catch data from the serial port and process it.
final performance is that it can stream at about 7-8 fps and recognize faces, wifi streaming is better at roughly 13-15 fps.
feel free to use the code , and its a great project to learn working with the esp eye.
